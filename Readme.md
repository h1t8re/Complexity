#### Complexity of **n!** is:
$$n! = 1.2.3..n$$
$$=>$$ 
$$ 1.2.3..n = 1.(1+1).(1+1+1)..(n)$$
$$=>$$ 
$$1.(1+1).(1+1+1)..(n) = \prod_{i=1}^{n} i$$
$$=>$$ 
$$\prod_{i=1}^{n} i = \prod_{i=1}^{n} \sum_{j=1}^{i} 1$$
#### Complexity of **x^{2}** is :
$$x^{2} = x.x$$
$$\sum_{i=1}^{2}\sum_{i=1}^{x} 1$$
##### By this
#### The complexty of x^{n} is:
$$x^{n} = x.x.(n).x$$
$$\sum_{i=1}^{n}\sum_{i=1}^{x} 1$$
